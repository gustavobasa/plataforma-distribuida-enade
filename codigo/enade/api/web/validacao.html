Validação manual da extração (RNF03) Baixar CSV Voltar à busca

Compare a página original (esquerda) com o que foi extraído (direita) e marque cada critério. Use N/A quando o critério não se aplica (ex.: alternativas em questão discursiva, mídia em questão só de texto). Use as setas ou os botões para navegar. As respostas são salvas no servidor ao clicar em “Salvar e próxima”.
